## Why Shared Standards?

These standards are maintained in the `types` submodule because:
- **Consistency**: All be-* projects follow the same conventions
- **Single source of truth**: Updates apply to all projects
- **Easier maintenance**: Update once, benefit everywhere
- **Onboarding**: New contributors learn one set of standards
